The "Where to?" region filter chip for THE DRIVES list. Pine-outlined when idle, pine-filled when a region is selected; a trailing chevron signals it opens a picker.

```jsx
<FilterChip label="North Shore" active onPress={openPicker} />
<FilterChip label="All regions" onPress={openPicker} />
```

Pine, never amber — the home reserves its one amber glow for the parked car token.

The enamel travel pill — stop types, tour length, the joke meter, status. Outlined by default; `filled` for a solid disc.

```jsx
<Badge tone="amber" label="42 MIN" />
<Badge tone="teal" icon="scenic" label="Scenic" />
<Badge tone="pine" filled label="Story" />
```

Tones: `pine` `amber` `teal` `rust` `neutral` — each a contrast-safe pairing. Stop types map to tones via `stopTone()` (story→pine, scenic→teal, break→amber).

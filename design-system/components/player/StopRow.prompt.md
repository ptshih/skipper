A single stop row with three glance-states. Usually built for you by `StopList`; reach for it directly only to compose a custom itinerary.

```jsx
<StopRow name="Emerald Bay Overlook" sublabel="Scenic" icon="scenic" state="active" />
```

States: `upcoming` (calm glyph + name) · `active` (sunken you-are-here well + pine accent + bold name — never amber) · `passed` (dimmed + a quiet check).
